# Fortune in a Pot

One kind, funny fortune for the houseplant on the windowsill, written as a
single line of 107 characters — well inside the 120-character gate. A small
joke a plant lover laughs at (the keeper bragging about the plant to guests
who never asked), warm with no doom, in the cadence of a prediction.

> You will catch the best sunbeam on the sill, and your keeper will brag about you to guests who never asked.

## Run it

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (or `./output/entry.txt` when
`/output` is not writable), one line, UTF-8, 107 characters.
